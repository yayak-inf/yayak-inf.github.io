Tools Security Testing Populer

Materi 9

Security Testing

Berikut tools yang sering digunakan untuk pemindaian kerentanan dan pengujian keamanan aplikasi web.

OWASP ZAP

Open-source web scanner

Memindai kerentanan aplikasi web dan melakukan pengujian berbasis proxy.

Cocok untuk praktikum: automated scan, spider, dan laporan temuan.

Burp Suite

Intercepting proxy

Menganalisis dan memodifikasi request/response HTTP untuk pengujian manual.

Fitur umum: Repeater, Intruder, Scanner (edisi tertentu).

Nikto

Web server scanner

Memeriksa konfigurasi server web dan file/endpoint yang berisiko (misconfig, versi usang).

Umum dipakai untuk baseline assessment pada web server.

Metasploit

Framework eksploitasi

Mendukung simulasi serangan dan validasi kerentanan pada lingkungan uji.

Gunakan hanya pada target legal dan lingkungan lab yang aman.

Catatan: Untuk praktikum kelas, gunakan aplikasi demo dan izin yang jelas. Hindari pengujian pada sistem produksi tanpa otorisasi.
