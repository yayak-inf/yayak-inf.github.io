Cara Mengatasi

Pertemuan 9

Security Testing

Empat praktik berikut membantu menutup celah umum seperti SQL Injection, XSS, dan kelemahan autentikasi.

Validasi & sanitasi input

Input diperlakukan sebagai data

Terapkan whitelist format (panjang, karakter, tipe), sanitasi, dan tolak input anomali.

Contoh: batasi panjang username, validasi email, normalisasi input.

Prepared statement

Parameterized query

Pisahkan perintah SQL dan nilai input agar input tidak mengubah struktur query.

Hindari merangkai query dengan string concatenation.

Escape / encode HTML

Cegah XSS pada output

Jangan render input user sebagai HTML/JS. Encode saat ditampilkan di halaman.

Gunakan templating/escaping bawaan framework bila tersedia.

Authentication yang aman

MFA, rate limiting, session

Terapkan kebijakan password, rate limiting, manajemen sesi, dan MFA bila memungkinkan.

Kurangi risiko brute force & account takeover.

Catatan: Praktik mitigasi sebaiknya dipadukan dengan pengujian rutin (scanning, pentest) dan review konfigurasi keamanan.
