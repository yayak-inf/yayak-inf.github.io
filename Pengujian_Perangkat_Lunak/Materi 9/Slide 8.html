Cross Site Scripting (XSS)

Materi 9

Security Testing

Ancaman pada aplikasi web yang memanfaatkan input tidak tervalidasi sehingga script berbahaya ikut dijalankan di browser pengguna.

Definisi

XSS adalah serangan dengan menyisipkan script ke halaman web sehingga dijalankan oleh browser korban.

Terjadi ketika aplikasi menampilkan kembali input pengguna tanpa validasi/sanitasi atau tanpa encoding output yang tepat.

Mencuri Cookie

Mengambil session cookie untuk mengambil alih akun.

Mencuri Data

Merekam input pengguna atau melakukan data exfiltration.

Aksi Atas Nama User

Memanipulasi tampilan/aksi saat user sedang login.

Catatan: XSS dapat bersifat stored, reflected, atau DOM-based—tergantung lokasi penyisipan dan eksekusi script.
