Tugas Praktikum: Security Testing

Materi 9

Security Testing

Lakukan pengujian sederhana pada lingkungan uji yang berizin untuk mengevaluasi ketahanan form login/website terhadap input berbahaya.

Objek & Skenario Uji

Objek uji

Form Login / Website sederhana (pilih yang tersedia dan Anda miliki izin untuk menguji).

3 skenario pengujian

1

Input normal (valid)

Pastikan alur login berjalan sesuai spesifikasi.

2

Uji SQL Injection

Coba input yang memanipulasi query (mis. payload sederhana).

3

Uji XSS

Coba input script dan amati apakah dieksekusi di browser.

Output yang Dikumpulkan

Screenshot hasil testing

Bukti input yang dicoba dan respons aplikasi (ditolak/berhasil/error).

Analisis aman / tidak aman

Jelaskan indikasi kerentanan berdasarkan hasil observasi.

Rekomendasi perbaikan

Usulkan mitigasi (validasi input, prepared statement, escaping, dll.).

Etika & keselamatan: lakukan pengujian hanya pada sistem yang Anda miliki izin, gunakan environment uji, dan dokumentasikan semua langkah.
