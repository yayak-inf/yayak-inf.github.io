Studi Kasus: Form Login Sederhana

Materi 9

Security Testing

Latihan yang aman dan mudah untuk memahami cara menguji input berbahaya (SQLi & XSS) pada aplikasi.

Studi Kasus

Menguji keamanan form login dari input berbahaya.

Tujuan pengujian: memastikan input pengguna tidak dapat digunakan untuk bypass autentikasi (SQL Injection) maupun mengeksekusi script di browser (XSS).

Praktik dilakukan pada aplikasi/website latihan agar aman (tidak merusak sistem produksi).

Objek Uji

Field username & password pada form login.

Target Risiko

SQL Injection untuk bypass autentikasi.

Target Risiko

XSS untuk menjalankan script di browser.

Catatan: gunakan lingkungan uji (localhost/sandbox). Hindari pengujian pada layanan publik tanpa izin.
