Materi 9

Security Testing

Tujuan uji ini adalah memeriksa apakah aplikasi menampilkan kembali input pengguna tanpa encoding, sehingga script bisa dieksekusi di browser.

Langkah Uji (Aman)

1) Pilih field teks (mis. username, komentar)

2) Masukkan payload XSS sederhana

3) Submit dan amati respons halaman

Catatan: lakukan hanya pada test environment yang Anda miliki izin untuk menguji.

Input uji (contoh payload sederhana)

Field teks (contoh):

<script>alert('XSS')</script>

Interpretasi umum:
jika output tidak di-encode, browser mengeksekusi script.

Ekspektasi & Indikasi Kerentanan

Sistem aman (lebih baik)

Input ditampilkan sebagai teks (di-encode), tidak ada popup, dan tidak ada script yang berjalan.

Sistem rentan

Jika muncul popup alert → indikasi kuat XSS.

Etika: Pengujian harus berizin, terkontrol, dan terdokumentasi. Hindari pengujian pada sistem publik/produksi tanpa persetujuan.
