Jenis Ancaman Umum

Materi 9

Security Testing

Empat ancaman berikut sering muncul pada aplikasi web. Pahami konsepnya sebelum melakukan pengujian.

SQL Injection

Manipulasi query database

Input disisipkan perintah SQL untuk mengubah logika query (mis. bypass login atau membaca data).

Contoh dampak: data sensitif terekspos, perubahan data tanpa izin.

Cross Site Scripting (XSS)

Script berjalan di browser

Penyerang menyisipkan script (JavaScript) ke halaman untuk mencuri cookie, token, atau melakukan aksi atas nama user.

Contoh dampak: session hijacking, defacement, phishing.

Broken Authentication

Kelemahan mekanisme login

Desain/implementasi autentikasi yang lemah (password mudah, tanpa rate limit, manajemen sesi buruk).

Contoh dampak: pengambilalihan akun (account takeover).

Data Exposure

Data sensitif terekspos

Kerahasiaan data tidak terjaga (mis. konfigurasi salah, enkripsi lemah, data ditampilkan berlebihan).

Contoh dampak: kebocoran PII, token, atau kredensial.

Catatan: Pada pertemuan berikutnya, tiap ancaman akan dibahas beserta contoh input uji yang aman pada lingkungan praktikum.
