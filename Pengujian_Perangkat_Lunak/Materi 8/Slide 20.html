Tugas Praktikum

Tugas Praktikum: Performance Testing

Lakukan pengujian performa fitur login menggunakan Apache JMeter pada 3 level beban. Kumpulkan bukti eksekusi dan analisis singkat berbasis metrik.

Skenario Uji (Wajib)

Jalankan satu per satu dan bandingkan hasilnya

50 / 100 / 200

Level 1

50 user login bersamaan

baseline

Level 2

100 user login bersamaan

medium load

Level 3

200 user login bersamaan

target

Catatan eksekusi

Gunakan konfigurasi yang konsisten antar level (endpoint, durasi, data uji). Jika perlu, atur ramp-up agar beban naik bertahap.

Instruksi Pelaksanaan (Ringkas)

Checklist agar run dan hasil mudah dianalisis

do this

Thread Group

Set users: 50 → 100 → 200 (jalankan terpisah).

HTTP Request (Login)

Konfigurasi URL/method/payload dan header yang benar.

Metrik yang dianalisis

Response time (P95), throughput, error rate.

Validasi hasil

Jika error tinggi/timeout, catat indikasi bottleneck.

Tips

Untuk analisis, fokus pada perbandingan antar level (50 vs 100 vs 200). Jelaskan tren, bukan hanya angka.

Output yang Dikumpulkan

Minimal 3 artefak untuk penilaian

Deliverables

1) Screenshot hasil testing

Bukti eksekusi per level (50/100/200) dari listener/report.

2) Grafik performa

Minimal 1 grafik (mis. P95 vs user, error vs user, throughput vs user).

3) Analisis singkat

Ringkas: tren + temuan + rekomendasi perbaikan (jika ada).

Rubrik cepat (arah penilaian)

Kelengkapan artefak, konsistensi skenario, dan ketepatan interpretasi metrik (latensi/throughput/error).

Contoh Grafik (Format)

Ilustrasi: hubungan beban vs metrik (bukan data wajib)

example

P95

Cantumkan P95 agar terlihat konsistensi latensi.

Error

Grafik error membantu melihat titik overload.

Target akhir

Tunjukkan apakah performa login memburuk saat user naik dan jelaskan kemungkinan penyebab (aplikasi/DB/jaringan).

Kumpulkan artefak per level beban (50/100/200) agar analisis dapat dibandingkan secara objektif.
