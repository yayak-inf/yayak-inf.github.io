Load Testing

Mengukur performa sistem pada beban normal/ekspektasi untuk memastikan layanan tetap responsif dan stabil.

Tujuan

Menilai apakah sistem mampu menangani beban pengguna harian dengan response time yang sesuai target, error rendah, serta throughput stabil.

Error rendah

HTTP 5xx/timeout minimal dan tidak meningkat seiring beban.

Resource wajar

CPU/RAM/DB connection tidak “menempel” di batas atas.

Contoh Implementasi

Skenario nyata untuk uji beban

Scenario

Kasus: Aplikasi Web (fitur utama)

Jalankan 100–1000 user yang mengakses fitur utama bersamaan.

Pola beban: ramp-up bertahap → steady state (mis. 10 menit) → ramp-down.

Catat metrik: P95 response time, throughput, error.

Output yang diharapkan

Sistem tetap stabil pada beban target, serta ada data untuk keputusan optimasi (cache, query, scaling).

Setelah load testing, lanjutkan ke stress testing untuk mencari batas maksimum sistem.
