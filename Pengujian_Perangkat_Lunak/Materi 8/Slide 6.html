Jenis Pengujian

Jenis-Jenis Performance Testing

Empat pendekatan umum untuk menguji performa dari sisi kapasitas, ketahanan, dan perilaku sistem saat beban berubah.

Load Testing

Beban normal / ekspektasi harian

Normal Load

Response Time

Latensi pada beban wajar

Throughput

Kapasitas request/detik

Stability

Error rendah & konsisten

Contoh

100–1000 user mengakses fitur utama secara bersamaan.

Stress Testing

Di atas kapasitas maksimum

Break Point

Failure Mode

Timeout, crash, queue penuh

Resilience

Degradasi terkontrol

Bottleneck

Titik hambat resource

Contoh

Beban dinaikkan bertahap hingga sistem tidak merespons (crash/timeout).

Spike Testing

Lonjakan trafik mendadak

Sudden Surge

Ramp-Up

Naik cepat (detik/menit)

Queueing

Antrian & backpressure

Alerting

Deteksi incident lebih cepat

Contoh

Trafik melonjak dari 100 user ke 10.000 user dalam hitungan detik.

Volume Testing

Ukuran data sangat besar

Big Data

Data Size

Record membesar (juta+)

Query

Index, join, pagination

I/O

Disk, cache, koneksi DB

Contoh

Operasi baca/tulis pada database dengan jutaan record.

Pemilihan jenis uji bergantung pada tujuan: kapasitas harian, batas maksimum, lonjakan, atau volume data.
