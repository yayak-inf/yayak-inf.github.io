Tools: Apache JMeter

Pengenalan Apache JMeter

Tools open-source untuk menjalankan load & performance testing—mudah dipakai, fleksibel, dan cocok untuk praktikum berbasis skenario.

Apa itu JMeter?

JMeter membantu mensimulasikan banyak pengguna (virtual users) yang mengirim request ke aplikasi/layanan untuk mengukur response time, throughput, dan error.

Kemampuan Utama

Fitur yang sering dipakai dalam performance testing

GUI / CLI

Load Testing

Menguji beban normal/target (mis. 50–200 user) untuk melihat kestabilan.

Performance Testing

Mengukur metrik (P95, throughput, error) dan membandingkan hasil antar iterasi.

API Testing

Mendukung HTTP/HTTPS untuk REST API (login, token, request body, headers).

Skenario & Parameter

Thread Group, ramp-up, loop, serta input variabel untuk data uji.

Listener & Report

Melihat hasil (mis. View Results Tree) dan rekap metrik untuk analisis.

Mengapa cocok untuk praktikum?

Cepat dipelajari dan mudah dievaluasi

Reasoning

Setup sederhana

Instalasi mudah dan dapat menjalankan skenario login HTTP tanpa banyak kode.

Hasil mudah dibaca

Listener membantu mahasiswa melihat request/response, error, dan ringkasan metrik.

Reproducible

Skenario dapat disimpan dan dijalankan ulang untuk membandingkan sebelum/sesudah optimasi.

Catatan praktikum

Untuk menjaga akurasi, jalankan beban dari mesin yang memadai dan hindari listener berat saat skala besar (gunakan report ringkas).

Alur Praktikum (ringkas)

Dari skenario ke analisis

6 steps

1 Thread Group

Set user, ramp-up, loop.

2 HTTP Request

Isi URL login, method, body.

3 Data & Header

Parameter user/CSV (opsional).

4 Listener

Lihat hasil dan ringkasan.

5 Run Test

Jalankan 50/100/200 user.

6 Analisis

Bandingkan latensi & error.

Fokus praktikum: uji endpoint login pada beberapa level beban dan interpretasi metrik.
