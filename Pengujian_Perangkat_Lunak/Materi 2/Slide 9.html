Tahap Ketiga STLC

Test Case Development

Pada tahap ini, tim QA merancang skenario pengujian yang detail. Fokus utamanya adalah membuat Test Case dan menyiapkan Test Data yang diperlukan untuk memvalidasi fungsi sistem.

Penyusunan Skenario

Mencakup skenario positif (alur normal) dan negatif (error handling).

Persiapan Data Uji

Menyiapkan data dummy yang valid dan invalid untuk eksekusi.

Contoh: Test Case Login

Username & Password Benar

Harapan: Berhasil masuk ke dashboard

Password Salah

Harapan: Muncul pesan error "Password salah"

Field Kosong

Harapan: Validasi "Data tidak boleh kosong"

Akun Terkunci

Harapan: Redirect ke halaman bantuan/unlock
