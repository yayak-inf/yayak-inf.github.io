Manual Testing

Analisis kelebihan dan kekurangan pengujian manual.

VS

Kelebihan

Fleksibel

Tester dapat beradaptasi dengan cepat terhadap perubahan UI/UX tanpa perlu menulis ulang script.

Exploratory Testing

Sangat cocok untuk menemukan bug tak terduga yang mungkin terlewat oleh skrip otomatis yang kaku.

Minim Setup Tools

Tidak membutuhkan instalasi tools kompleks atau keahlian coding khusus di awal proyek.

Kekurangan

Memakan Waktu

Eksekusi manual jauh lebih lambat dibandingkan komputer, terutama untuk pengujian berulang.

Rentan Human Error

Tester bisa lelah atau kurang teliti, menyebabkan bug terlewat atau hasil tes tidak akurat.

Sulit Regression

Tidak efisien untuk regression testing skala besar yang harus dijalankan setiap ada update kode.
