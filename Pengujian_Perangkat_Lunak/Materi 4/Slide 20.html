1 Akses Link Pengujian

https://yayak-inf.github.io/Pengujian_Perangkat_Lunak/Tugas/Tugas1/login.html

2 Rancang Test Case

Buat minimal 5 Test Case mencakup:

  • Skenario Positif (Data Valid)
  • Skenario Negatif (Password Salah, Email Tidak Valid, Field Kosong)

Dengan ketentuan:

  • Username : admin@gmail.com
  • Password : admin123

3 Format Laporan

Kumpulkan dalam format PDF dengan tabel berisi: ID Test, Langkah, Input Data, Output (Harapan vs Aktual), Status (Pass/Fail).
