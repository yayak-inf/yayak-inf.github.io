Bagian 1 - Pendekatan

Teknik Black-box Testing

Empat teknik populer untuk menemukan kesalahan fungsional berdasarkan variasi input data.

Equivalence Partitioning

Membagi domain input menjadi kelas data valid & tidak valid untuk mengurangi test case tanpa mengurangi efektivitas.

Boundary Value Analysis

Fokus pada nilai batas (minimum & maksimum).

Decision Table Testing

Menggunakan tabel logika untuk memetakan kombinasi kondisi input kompleks.

State Transition Testing

Memvalidasi perubahan status sistem akibat event atau input.

Tujuan Utama

Menemukan kesalahan logika fungsional & validasi input
