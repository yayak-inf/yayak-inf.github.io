Bagian 1: Pendekatan Pengujian

Black-box Testing

Memahami konsep pengujian fungsionalitas tanpa melihat struktur internal.

Definisi

Teknik pengujian perangkat lunak di mana fungsionalitas sistem diuji tanpa mengetahui struktur internal kode program, detail implementasi, atau jalur internal.

Fokus Utama Tester:

Input

Data yang dimasukkan ke sistem

Output

Hasil keluaran yang diharapkan

Fungsionalitas

Kesesuaian dengan requirement bisnis

MODEL KONSEPTUAL

INPUT

Test Data

SYSTEM

HIDDEN

OUTPUT

Actual Result

Perbandingan: Tester membandingkan Actual Result dengan Expected Result. Apa yang terjadi di dalam kotak "System" tidak relevan bagi tester.
