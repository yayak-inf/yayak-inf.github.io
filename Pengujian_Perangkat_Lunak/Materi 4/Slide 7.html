Bagian 1: Pendekatan Pengujian

White-box Testing

Memahami struktur internal, logika, dan alur eksekusi kode program.

Definisi

Teknik pengujian perangkat lunak yang dilakukan dengan memahami dan menguji struktur internal kode program secara mendetail.

Area Pengujian Utama:

Percabangan (Branching)

Menguji kondisi if-else dan switch

Perulangan (Looping)

Memastikan loop (for, while) berjalan benar

Path Execution

Memverifikasi semua jalur kode yang mungkin

INTERNAL STRUCTURE VIEW

INPUT

calculateTax.js
function calcTax(income) {
if (income < 5000) {
return 0;
} else if (income > 10000) {
// High tax bracket
return income * 0.2;
} else {
return income * 0.1;
}
}
