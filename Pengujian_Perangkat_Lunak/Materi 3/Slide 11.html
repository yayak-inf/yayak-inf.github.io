Security Testing

Pengujian Keamanan Sistem & Data

DEFINISI

Security Testing adalah pengujian untuk memastikan sistem aman dari ancaman, serangan siber, dan akses yang tidak sah.

Tujuan Utama

  • Mencegah kebocoran data sensitif pengguna.
  • Menghindari akses ilegal ke dalam sistem.
  • Melindungi integritas transaksi pengguna.
Contoh: SQL Injection
SELECT * FROM users WHERE username = 'admin' AND password = '' OR '1'='1';

Penguji mencoba memasukkan kode berbahaya (malicious code) pada form login untuk memanipulasi database dan masuk tanpa password yang valid.
