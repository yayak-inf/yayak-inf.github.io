Unit Testing

Pengujian Level Dasar (Low Level Testing)

Definisi

Unit Testing adalah pengujian pada bagian terkecil dari program, seperti fungsi (function) atau method secara terisolasi.

Ciri-Ciri Utama
  • Dilakukan oleh Developer
  • Fokus pada Logika Program
  • Biasanya menggunakan Automation
Contoh Penerapan

function hitungDiskon(total) {

if (total > 100000) {

return total * 0.10;

}

return 0;

}

Skenario: Memastikan fungsi memberikan diskon 10% jika total belanja > 100.000, dan 0 jika sebaliknya.

Jenis-Jenis Pengujian Perangkat Lunak
4
