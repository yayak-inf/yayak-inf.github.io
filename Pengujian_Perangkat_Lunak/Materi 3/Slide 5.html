Integration Testing

Pengujian Interaksi Antar Modul

DEFINISI

Integration Testing adalah pengujian untuk memastikan modul-modul yang telah diuji secara terpisah dapat bekerja dengan baik ketika digabungkan.

Tujuan Utama

Mendeteksi error atau bug yang terjadi pada interaksi & komunikasi data antar modul yang berbeda.

Contoh Penerapan
Modul Login
Request Data
Database User

Memastikan Modul Login sukses mengambil data dari Database User.
