Penerapan Berbagai Jenis Pengujian dalam Satu Sistem

1

Unit Testing

Level Terkecil (Code)

Skenario

Menguji fungsi perhitungan Total Belanja = (Harga x Qty) - Diskon.

2

Integration Testing

Interaksi Modul

Skenario

Memastikan modul Checkout dapat mengirim data ke Payment Gateway.

3

System Testing

Fungsi Menyeluruh

Skenario

Menguji alur lengkap: Login → Cari Barang → Add to Cart → Bayar.

4

Acceptance Testing

Validasi User

Skenario

Client/User asli mencoba aplikasi untuk memastikan kebutuhan bisnis terpenuhi.

5

Performance

Non-Functional (Load)

Skenario

Simulasi 10.000 user akses bersamaan saat Harbolnas (Flash Sale).

6

Security

Non-Functional (Safety)

Skenario

Menguji celah keamanan pada transaksi kartu kredit dan data pribadi.
