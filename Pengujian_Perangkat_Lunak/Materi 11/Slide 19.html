Identifikasi Masalah (Gejala)

Pengguna melaporkan dua isu kritis: Login Error (authentication timeout) dan Upload File Gagal saat mengirim tugas besar (>5MB).

Alur Penyelesaian Bug

1. Catat Bug
QA membuat tiket di Jira dengan log error & screenshot.
2. Prioritaskan
PM set ke "High" karena menghambat fungsi utama.
3. Perbaiki
Dev memperbaiki logic auth & config server upload.
4. Retest
QA memverifikasi fix di environment Staging.
5. Closed
Bug dinyatakan selesai dan dideploy ke Production.

Hasil Akhir

Sistem kembali stabil dan fungsionalitas pengguna pulih sepenuhnya.
