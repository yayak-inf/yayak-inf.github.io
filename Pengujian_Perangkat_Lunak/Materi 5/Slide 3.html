Apa itu Unit Testing?

Definisi Utama

Unit Testing adalah pengujian terhadap bagian terkecil dari sebuah perangkat lunak.

Focused on smallest logic units

Biasanya Menguji:

Fungsi (Functions)

Method

Class

Module Kecil

Tujuan Utama:

  • Memastikan setiap unit berjalan sesuai logika

  • Mendeteksi bug sejak awal pengembangan

  • Mempermudah proses debugging
