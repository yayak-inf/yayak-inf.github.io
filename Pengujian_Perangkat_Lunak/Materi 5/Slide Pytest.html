Latihan Unit Testing dengan PyTest

1️⃣ Pastikan Python Sudah Terinstal

Pytest membutuhkan Python versi 3.6 atau lebih baru.

python --version atau python3 --version
2️⃣ Instal PyTest Menggunakan pip
pip install pytest

Linux / Mac:

pip3 install pytest
3️⃣ Verifikasi Instalasi
pytest --version
4️⃣ Menggunakan PyTest dalam Proyek

Buat file test_sample.py:

def tambah(a, b): return a + b def test_tambah(): assert tambah(2,3) == 5

Jalankan pengujian:

pytest

Hasil Pengujian Berhasil

================ test session starts ================ collected 1 item test_sample.py . [100%] ================ 1 passed in 0.01s =================

Artinya fungsi berjalan dengan benar dan semua pengujian dinyatakan PASSED.
