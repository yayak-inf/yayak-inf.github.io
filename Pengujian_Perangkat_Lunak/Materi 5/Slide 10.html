Katalon Recorder untuk UI Testing

Apa itu Katalon Recorder?

Katalon Recorder adalah ekstensi Google Chrome untuk melakukan automation testing website tanpa coding. Mahasiswa cukup merekam aktivitas pengguna lalu menjalankan ulang pengujian secara otomatis.

Langkah Menggunakan Katalon Recorder
1

Install Extension

Buka Chrome Web Store → cari Katalon Recorder → klik Add to Chrome.

2

Mulai Recording

Klik ikon Katalon Recorder di Chrome lalu tekan tombol Record.

3

Lakukan Aktivitas Website

Login, klik menu, isi form, dan lakukan interaksi seperti pengguna biasa.

4

Stop Recording

Setelah selesai, klik tombol Stop untuk menyimpan skenario testing.

5

Jalankan Automation Test

Klik Play Suite dan lihat hasil pengujian otomatis PASS atau FAIL.
