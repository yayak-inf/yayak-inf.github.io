Contoh Unit Testing Sederhana (Java)

Kalkulator.java SOURCE CODE
public class Kalkulator {
public int tambah(int a, int b) {
return a + b;
}
}
KalkulatorTest.java JUNIT TEST
import static org.junit.jupiter.api.Assertions.*;
import org.junit.jupiter.api.Test;
class KalkulatorTest {
@Test
void testTambah() {
Kalkulator k = new Kalkulator();
// Memastikan 2 + 3 = 5
assertEquals(5, k.tambah(2, 3));
}
}

Logika Pengujian: Jika hasil kembalian metode tambah(2, 3) tidak sama dengan 5, maka unit test dianggap GAGAL (FAILED).
