project_pytest/ │ ├── kalkulator.py └── test_kalkulator.py
1️⃣ File Program — kalkulator.py
class Kalkulator: def tambah(self, a, b): return a + b def kurang(self, a, b): return a - b def kali(self, a, b): return a * b def bagi(self, a, b): if b == 0: raise ValueError("Tidak bisa dibagi nol") return a / b

👉 Ini adalah kode yang akan diuji (System Under Test).

2️⃣ File Testing — test_kalkulator.py
from kalkulator import Kalkulator k = Kalkulator() def test_tambah(): assert k.tambah(2, 3) == 5 def test_kurang(): assert k.kurang(10, 4) == 6 def test_kali(): assert k.kali(3, 5) == 15 def test_bagi(): assert k.bagi(10, 2) == 5 def test_bagi_nol(): import pytest with pytest.raises(ValueError): k.bagi(5, 0)
3️⃣ Jalankan Pengujian
pytest
