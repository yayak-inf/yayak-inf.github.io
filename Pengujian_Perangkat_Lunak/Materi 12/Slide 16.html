Studi Kasus: Sistem Login

Analisis fitur utama yang akan diuji dalam skenario pengujian.

1

Input Email

Kolom input untuk memasukkan alamat surel pengguna.

Fokus Pengujian:

  • Format valid (@, domain)
  • Input kosong
  • Case sensitivity
2

Input Password

Kolom input terenkripsi (masked) untuk kata sandi.

Fokus Pengujian:

  • Masking character (*)
  • Batas panjang karakter
  • Kombinasi huruf/angka
3

Tombol Login

Pemicu aksi untuk memvalidasi kredensial ke server.

Fokus Pengujian:

  • Fungsi klik
  • Redirect halaman
  • Pesan error/sukses
