ID Test Skenario Input Data Expected Result
TC-01

Login Valid

Menguji login dengan kredensial benar

Email: admin@test.com

Pass: admin123

Sistem menerima login dan me-redirect user ke halaman Dashboard.
TC-02

Password Salah

Menguji validasi keamanan

Email: admin@test.com

Pass: salah123

Sistem menolak login, tetap di halaman login, dan menampilkan pesan error: "Email atau password salah".

Tips Penulisan

Pastikan Expected Result tidak ambigu (contoh: jangan hanya tulis "Error", tapi tulis pesan error spesifik yang diharapkan muncul).

Pre-Condition

Untuk TC-01 dan TC-02, asumsikan akun dengan email admin@test.com sudah terdaftar di database.
